# Earlier experiments

This folder preserves the old autoencoder scripts, legacy generation/evaluation tools, environment snapshot and historical logs. These are not the recommended entry points for reproducing the text-conditioned paper.

Use `python -m archive.scripts.<name>` from the repository root when inspecting an older script. Historical reports are not the published benchmark table. The archived comprehensive evaluator and text-conditioning diagnostic do not carry the same conditioning/evaluation protocol as `scripts.generate`.

Redundant `ARCHITECTURE_DIAGRAM.md`, `PAPER_ARCHITECTURE.md` and the obsolete root evaluation guide were removed; earlier revisions remain in Git history.
